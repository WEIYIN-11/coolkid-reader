# 第 2 章　通文

> *築基初期・第二重「通文」*

入司第七天，尹知行做了一件後來被他自己稱為「**最蠢的開局**」的事。

他把雲書司的《探子手冊》抄了兩份，一份送漕運司、一份送鹽鐵司，附信：

> 「兩司探子若皆依此手冊行事，文書自通。」

第十天，兩份手冊都被退回來了。

漕運司的批註：「我司探子走水路、查漕糧，貴司手冊所言『城內布探』『腰牌持械』皆不適用。**另，我司無『推步』一說，回報自有祖制**。」

鹽鐵司的批註更短：「**鹽鐵密務，不從外法**。」

---

尹知行拿著兩份退件，去見溫止。

「司丞，兩司都不肯用統一的手冊。」

「嗯。」溫止頭也沒抬，「你拿你家的家規，要別人家照著過日子。人家為什麼要肯？」

「⋯⋯但格式不統一，文書就不通。」

「**誰跟你說「通」要靠「同」？**」

尹知行愣住。

溫止放下筆。

「你在雲書司，探子用什麼兵刃？」

「看任務。刀、弩、毒、帳冊⋯⋯」

「漕運司的探子會用船。鹽鐵司的探子會驗鹽的成色。你雲書司的探子會嗎？」

「⋯⋯不會。」

「所以**讓十三司的探子變成同一種探子，既不可能、也不該**。」溫止說，「漕運司的探子就該懂水路，鹽鐵司的就該懂鹽。**各司探子各有所長，這是天下之福**。」

「那要統一什麼？」

溫止從案上拿起一份驛遞的信封。

「你看這個信封。」他說，「**信封上寫什麼，天下統一**：收信人、地址、寄信人、急緩等級。**信裡寫什麼，各家自便**。」

「驛路只管信封，不管信。」溫止說，「**通文，通的是「封皮」，不是「內文」**。」

---

尹知行回到文書房，把這句話貼上牆：

> 通的是封皮，不是內文。

> **統一介面，不統一實作**。

然後他開始拆「封皮」── 一份任務令，**最少**要有哪些欄位，別司的人才能看懂？

他把漕運司、鹽鐵司、雲書司、刑部的任務令樣本並排攤開，逐欄比對。四司的任務令加起來有四十幾種欄位，但他發現 ──

**真正每司都有的，只有七個**：

```
一、案號     （這件事叫什麼編號）
二、事由     （查什麼）
三、轄區     （在哪查）
四、期限     （查到什麼時候）
五、密級     （誰能看）
六、回報節點 （多久回報一次、報給誰）
七、發令者   （誰下的令）
```

其他三十幾種欄位 ── 漕運司的「船籍」、鹽鐵司的「鹽引號」── 都是**各司的內文**，別司不需要懂。

---

第十五天，尹知行寫出第一版《通文式》：

```
《驛盟通文式・任務令》

凡跨司任務令，封皮必含七欄：

  案號：〔驛盟統一編號，格式：盟-年-流水號〕
  事由：〔一句話，不超過三十字〕
  轄區：〔州府名，從《天下州府名錄》中選，不得自創〕
  期限：〔起日—訖日，用朝廷曆法，不得用「兩月」「60日」等相對寫法〕
  密級：〔甲/乙/丙/丁 四級，附《密級對照表》：各司舊密級如何對應〕
  回報節點：〔每 N 日一報，N 為數字〕
  發令者：〔司名＋官職，從《十三司官制錄》中選〕

封皮之後，各司內文自便，驛盟不問。
```

每一欄他都寫死了**取值規則**：轄區必須從名錄裡選、期限必須是絕對日期、密級必須是四級之一。

**不准自由發揮** ── 自由發揮就是揚州案的根。

---

第二十天，他把《通文式》送兩司「試行」。

這次他學乖了，附信不寫「請依此行事」，寫的是：

> 「貴司文書一切如舊。**唯跨司案件**，請於原文書外加一頁封皮，封皮依此式。」
>
> 「封皮七欄，抄寫不過一炷香。**貴司內文，驛盟一字不改、一字不問**。」

漕運司七天後回：「可。」

鹽鐵司拖了十二天，回了一個條件：「密級對照表中，本司『三等密』對應『丙』，**但本司要保留「特密」一級，不入對照**。」

尹知行回信：「可。特密件不走驛盟，貴司自理 ── **本就該如此**。」

鹽鐵司隔天用印。

---

第三十五天，第一次試驗。

驛盟司擬了一個演習案：「查京畿東郊糧倉帳目」，同時發漕運司和鹽鐵司，兩司各派一個探子。

兩份任務令，**封皮一模一樣**：

```
案號：盟-元-0001
事由：查京畿東郊糧倉帳目有無虛報
轄區：京畿・通州
期限：三月初一—三月三十
密級：丙
回報節點：每五日一報
發令者：驛盟司・司丞溫止
```

兩個探子出發前，驛盟司讓他們互看了對方任務令的封皮。

漕運司的探子看了一眼就說：「同案、同轄區、同期限 ── **這位是同案的，不是奸細**。」

一句話。

揚州案裡十一天查不清的事，**封皮上一眼看清**。

---

第四十天，兩個探子合查回報。糧倉帳目沒問題，演習結束。

複盤的時候，鹽鐵司的探子說了一句讓尹知行記到本子上的話：

「以前看別司文書，像看番邦文字。**現在封皮一樣，就像兩個說不同方言的人，至少姓名籍貫寫法一樣 ── 能對上人**。」

尹知行在牆上加了一張紙條：

> 封皮七欄，欄欄寫死取值。

> **格式自由是互通之敵**。

> 你少給一分自由，天下多通一分。

---

那夜尹知行在牆前盤膝坐下、閉目。

這一張新貼的紙條化作微光、沉入丹田。

胸口熱了一下、又涼了一下。

自此尹知行修為 ── **築基初期・第二重「通文」**。

## 雜役筆記

*尹知行《諸探之約》第二章。*

**▍Interface vs Implementation（介面與實作）**

溫止的「封皮與內文」。

- **Interface（介面/封皮）**：對外承諾的格式 ── 統一、寫死、版本化
- **Implementation（實作/內文）**：內部怎麼做 ── 各自自由

「**統一介面，不統一實作**」是所有互通協議的第一原則。MCP 不管你的 server 內部用什麼語言、什麼資料庫 ── 只管你對外的訊息格式。

**▍Tool Definition（工具定義）**

Agent 世界的「封皮」。一個工具要被 agent 正確使用，必須宣告：

```json
{
  "name": "query_granary_records",
  "description": "查詢指定州府糧倉的入庫出庫紀錄。回傳最近 N 筆。",
  "inputSchema": {
    "type": "object",
    "properties": {
      "prefecture": { "type": "string", "enum": ["通州", "揚州", "..."] },
      "record_type": { "type": "string", "enum": ["入庫", "出庫", "全部"] },
      "limit": { "type": "integer", "minimum": 1, "maximum": 100 }
    },
    "required": ["prefecture", "record_type"]
  }
}
```

三件事：**name**（叫什麼）、**description**（什麼時候該用我 ── 寫給 LLM 看的，品質決定 agent 會不會用對）、**inputSchema**（參數格式）。

**▍JSON Schema**

定義「一份資料長什麼樣」的標準語言。尹知行的「欄欄寫死取值」：

- `enum`：只能從清單裡選（轄區必須從州府名錄選）
- `format` / `pattern`：格式限制（期限必須是絕對日期）
- `required`：必填欄位（七欄缺一不可）
- `type`：型別（回報節點必須是數字）

**Schema 越鬆，整合越痛**。「自由發揮就是揚州案的根」── 每個允許自由填寫的欄位，都是未來一次語義對不上的事故。

**▍Structured Output（結構化輸出）**

反方向的同一件事：要求 **LLM 的輸出**也遵守 schema。

Agent 回報不能是自由散文（「查得差不多了，感覺沒什麼問題」），要是結構化資料（`{"status": "clear", "evidence_count": 0, "confidence": 0.85}`）── 下游的程式或別的 agent 才能消化。

**▍Naming Convention（命名規範）**

跨系統的名字要可預測：

- 工具名：動詞開頭、snake_case（`query_granary_records`，不是 `GranaryHelper2`）
- 一個名字只指一件事（「報」和「聯」不能混用）
- 留版本空間（`v1/`、`v2/`）

**▍Adoption 的政治學**

尹知行第一次失敗（直接發手冊）vs 第二次成功（只加封皮）：

1. **不要求改變內部流程** ── 只在邊界加一層
2. **讓步換採用** ── 鹽鐵司的「特密不入對照」：協議覆蓋 95% 比堅持 100% 而沒人用好
3. **降低接入成本** ──「抄寫不過一炷香」

協議的價值 = 規範品質 × 採用率。**採用率是乘數**。

## 這一章你只要記得這三件事

1. **統一介面，不統一實作。** 通的是封皮，不是內文。要求別人改內部流程的協議，沒人會接。
2. **Tool definition 三件套：name、description、inputSchema。** description 是寫給 LLM 看的「什麼時候該用我」，品質決定 agent 用不用得對。
3. **格式自由是互通之敵。** enum 寫死取值、required 寫死必填、絕對日期取代相對寫法 ── 你少給一分自由，天下多通一分。

下一章：封皮通了，但鹽鐵司的探子想查雲書司的卷宗，還是得「派人上門、遞函、等回函」── 十天起跳。尹知行要把雲書司的卷宗庫，變成一座**別司探子隨到隨查**的驛站。**立驛**。
