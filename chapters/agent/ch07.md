# 第 7 章　內省

第三百天。

探子 #29 從冀州布的調查回司，**自信滿滿**。

「**司丞**！」#29 進門就笑，「**冀州布弊端**、**我抓到大魚了**！」

他攤開證據卷。

「**冀州布商會「**鴻運號**」**虛報原料進貨、實際少付織工工資三成。**我蒐集了三條證據**：第一，**鴻運號的進貨單**顯示「**棉花 5000 斤**」。**第二，**織工口供**說「**他們只看到 3500 斤**」。**第三，**織工的薪冊**顯示工資少於官方標準**。**鴻運號掌櫃「**樊志強**」**就是主使**！**」

蕭決翻證據。

從表面看，三條證據聯起來，**結論合理**。

但蕭決有個習慣 ── **任何「**看起來太對**」的結論，先反問一次**。

「⋯⋯**#29**。」蕭決說，「**我問你三個問題**。」

---

「**第一**：**「**棉花 5000 斤**」**和「**織工看到 3500 斤**」這兩個數字之間的 1500 斤差距，**有沒有可能是「**運輸損耗+倉儲折損+水分蒸發+裁剪損失**」？**」

#29 愣了一下。

「⋯⋯**理論上有可能**。**但 30% 損失太大**了**。」

「**冀州布商業界平均的損耗率你查過嗎**？」

「⋯⋯**沒**。」

「**好。**第二問**：**織工說「**他們只看到 3500 斤**」── 他們是「**全部織工都看過全部進貨**」嗎**？**還是只看過自己經手的部分**？」

「⋯⋯**是只看過自己經手的**。」

「**那「**全部織工**」加起來經手量是多少**？**1500 斤的差距如果有一半在「**另一組織工**」**手上，**他們不就抓不到**？**」

#29 沉默。

「**第三問**：**樊志強的薪冊「**少於官方標準**」 ── 你比對的是「**現行官方標準**」嗎？還是「**樊志強簽契時的標準**」？」

「⋯⋯**現行的**。」

「**現行標準是新訂的**。**樊志強跟織工的契是兩年前簽的**。**兩年前的標準你查了嗎**？」

「⋯⋯**沒**。」

#29 開始臉色發白。

---

蕭決翻冀州布商業會手冊。

「**冀州布商業平均棉花進貨損耗率：18%**。」蕭決唸給 #29 聽，「**鴻運號的 30% 確實偏高**。**但只「**偏高 12%**」，**不是「**虛報 30%**」**。」

「⋯⋯」

「**織工說 3500 斤 ── 這是他們組看到的**。**鴻運號用六組織工**。**如果分配不均，其他五組可能看到更多**。**1500 斤分散在六組裡，**平均每組看到 250 斤差異 ── 在「**搬運**」過程中分批進倉、很容易誤判**。」

「⋯⋯」

「**樊志強兩年前簽契時的織工工資標準**是月銀 1.2 兩**。**現在標準是 1.5 兩**。**樊志強付 1.3 兩 ── **比兩年前高、比現在低**。**他沒有「**違法**」**，**只是「**沒跟上漲**」**。**」

#29 臉色全白。

「⋯⋯**司丞**。**我犯了嚴重的錯**。**如果我們去找樊志強麻煩，他可能會被冤枉**。**而且我們會丟臉**。**」

蕭決點頭。

「**所以**。」蕭決說，「**我們現在做什麼**？」

---

#29 那個下午做了兩件事。

第一，**重新跑一次推步**，這次假設「**樊志強無罪**」：

```
觀察：棉花損耗 30%（比平均 18% 偏高）
思考：偏高可能性 ── (a) 真虛報 (b) 個別批次品質差 (c) 樊家管理鬆散
行動：對「(b) 品質差」查鴻運號的「**進貨原料來源**」、看是否單一供應商。

觀察：鴻運號近兩年棉花全部來自「**寧州棉農合作社**」。
思考：寧州棉花品質有沒有差過？
行動：查寧州近兩年棉花品質報告。

觀察：寧州 2024 棉花因水患品質下降、損耗率市場一致認為 25%-30%。
思考：「**鴻運號損耗 30%**」很可能是「**寧州棉花因水患品質差**」的結果。
      與「樊志強舞弊」無關。
行動：擴大查訪其他用寧州棉花的冀州布商。

觀察：另外四家冀州布商也用寧州棉花，損耗率分別為 28%、29%、31%、26%。
思考：鴻運號 30% 是「**市場一致水準**」，**不是異常**。
      之前的弊端結論不成立。
行動：撤回「樊志強舞弊」結論。
```

#29 用四輪推步，**自己推翻了自己**。

第二，他重寫**回司報告**：

```
冀州布調查結論

最初假設：鴻運號掌櫃樊志強虛報原料進貨、剋扣織工工資。

最初證據：（三條）

複查：對最初證據進行壓力測試後，發現：
  1. 棉花損耗 30% → 屬「**寧州 2024 棉花因水患品質下降**」之市場常態
  2. 織工「**只看到 3500 斤**」→ 屬「**單組分到的進貨**」非「**全進貨**」
  3. 工資少於現行標準 → 但符合契簽時（兩年前）標準

最終結論：冀州布鴻運號**無明顯舞弊**。

附議：
  - 寧州棉花 2024 損耗仍待朝廷補貼或政策應對
  - 織工工資標準兩年未跟上實際物價、建議官方修訂
```

蕭決把這份「**自我糾正後**」的報告呈給嚴司丞。

---

嚴司丞看了三遍。

「⋯⋯**蕭決**。」嚴司丞說，「**過去十年雲書司沒有任何探子「**回司之後自己推翻自己結論**」**。」

「⋯⋯」

「**從來都是「**回司報告**」 + 「**司丞認定**」 → 「**朝廷處置**」**。**錯了就錯了**，**沒人回頭看**。」

「⋯⋯」

「**你這次「**讓 #29 自己推翻自己**」 ── 這比抓到真弊端還重要**。」嚴司丞說，「**雲書司過去多少次「**沒舞弊的人被冤枉**」？我們沒辦法統計**。**因為沒人回頭看**。**」

蕭決點頭。

「**「**結論看起來對**」 ≠ 「**結論真的對**」**。」蕭決說，「**結論越「**漂亮**」、**越要反問一次**。**」

「⋯⋯**這個方法**。」嚴司丞說，「**叫什麼**？」

「**內省**。」蕭決說，「**或叫「**自核**」**。**」

---

第三百零五天，蕭決在《探子手冊》第七章開頭寫：

```
內省 = 「**自己反問自己**」**

每一個結論寫完，**先反問三個問題**：

一、有沒有「**反向解釋**」？── 同樣的證據能否支持完全相反的結論？
二、有沒有「**遺漏的變數**」？── 我有沒有忽略某個重要因素？
三、有沒有「**比對基準**」？── 我說「**偏高**」、跟誰比？

通過三問還站得住的結論 ── 提交。
任何一問動搖的 ── 回去重跑。
```

---

第三百一十天，新派出去的探子 **#48** 接到「**南州金舖弊端**」任務。

他帶著任務令、工具包、和 ── **內省三問檢核表**。

四週後，#48 第一份結案報告：

```
[初稿結論]
南州「**真金號**」金舖虛報黃金含量、實際成色低於官標 5%。

[內省檢核]
反向解釋：成色 5% 的偏差可能是「**煉金工藝差異**」（每家金舖工藝不同）。
        → 我查過南州五家金舖、平均偏差 1-2%。真金號 5% 顯著高於市場。
        → 反向解釋不成立。

遺漏變數：真金號是否「**新近改了工藝**」、或「**新進原料來源不穩**」？
         → 已查、真金號近一年無工藝或原料變更。
         → 無遺漏變數。

比對基準：「**官標含量**」用的是哪個版本？
         → 用「**現行 2026 版**」。真金號簽工標準用的也是現行版。
         → 基準正確。

結論：通過三問。提交。
```

蕭決看完，笑了一下。

#48 完全內化了內省三問。**他自己會反問自己**。

不需要回司之後讓蕭決問。

---

那晚蕭決在第七章末尾寫：

> **內省的兩個層次**：

> **第一層**：寫結論之後反問自己。
> **第二層**：寫結論之前，**先列出「**可能讓結論不成立的條件**」，主動去查**。

> 第一層是「**回頭看**」**。
> 第二層是「**主動避免錯**」**。

> 真正的好探子做兩層。**寫結論之前已經把反向都查過**。

下一章他要處理：**東陲三州調查 11 個探子並行 ── 探子之間其實會「**互相幫**」、也會「**互相擾**」**。**怎麼讓他們協作**？**那是「**群行**」**。

## 雜役筆記

*蕭決《探子手冊》第七章 ── 內省。*

**▍Reflection / Self-Critique（反思 / 自我批判）**

讓 agent **自己反問自己「**這個答案對嗎**」**。Agent 設計裡品質提升最快的技術之一。

**▍兩個變種**

**A. Self-Refine（自我精修）**：寫完答案後 reflect、改答案、再 reflect、再改⋯⋯直到滿意。
- 論文：Madaan et al., 2023
- 適合：寫作、code、設計

**B. Reflexion（自反思）**：失敗了之後，明確寫「**為什麼失敗**」、學習下次怎麼做。
- 論文：Shinn et al., 2023
- 適合：探索性任務、agent 跑多次

**▍實作模式**

```
Step 1: Generate（生答案）
Step 2: Critique（反問）
  - 結論的「**反向解釋**」有沒有？
  - 有沒有遺漏變數？
  - 比對基準對嗎？
  - 邏輯鏈完整嗎？
Step 3: Refine / Retry（改 / 重做）
  - 若 critique 找到問題 → 改答案
  - 若 critique 通過 → 提交
Step 4: 重複 1-3 直到通過或達 max iterations
```

**▍Self-Critique vs Verifier Model**

| 模式 | 描述 | 優缺 |
|---|---|---|
| Self-Critique | 同一個 agent 自己批判自己 | 簡單、但同一個模型可能有同樣盲點 |
| Verifier Model | 另一個獨立模型負責驗證 | 更獨立、但要管兩個模型 |
| Multi-Critic | 三個獨立 agent 各自批判 | 最嚴、最貴 |

**▍最常見的反問模板**

蕭決的「**三問**」：

```
1. 反向解釋（counter-explanation）：同樣的證據能否支持相反結論？
2. 遺漏變數（missing variables）：有沒有忽略重要因素？
3. 比對基準（baseline）：「**異常**」是跟什麼比？
```

業界更廣的清單：

```
1. 假設 vs 事實：哪些是我假設的、哪些有實證？
2. 樣本偏誤：我的樣本是否代表全體？
3. 因果 vs 相關：我看到的是相關還是因果？
4. 邏輯跳躍：A → B → C 之間有沒有沒驗證的步驟？
5. 反例：能不能找出一個反例？
6. 邊界條件：在極端情況下我的結論還成立嗎？
7. 利益相關者：我的結論會不會偏向某一方？
```

**▍Reflection 的成本**

每次 reflection 都要再呼叫一次 LLM。

```
單次回答：1 次 LLM call
Self-Refine（3 輪）：4 次 LLM call（generate → critique → refine → critique）
Multi-Critic（3 critic）：4-5 次 LLM call
```

**所以不是每個答案都該 reflect**。標準：

- 高風險決策 → 必 reflect
- 重複性低風險工作 → 跳過
- 中等風險 → 一次 reflect

**▍Constitutional AI（憲法 AI）**

Anthropic 對 Claude 的訓練方式。給模型一套「**永遠遵守的原則**」、模型自己用原則檢查自己的輸出。

**本質就是「**內建的 reflection**」**。

**▍實務工具**

- *LangChain Reflection / Self-Critique*
- *DSPy ReAct + Reflection*
- *AutoGen GroupChat with critic*
- *CrewAI Crew with reviewer agent*

**▍最重要的一句**

> 結論越「**漂亮**」、越要反問一次。

> Agent 寫出來的東西看起來都「**很合理**」**。

> 「**看起來合理**」**和「**真的對**」**之間隔了「**內省**」**這一步**。

## 這一章你只要記得這三件事

1. **每個 agent 結論寫完，反問三個：反向解釋 / 遺漏變數 / 比對基準。** 通過三問才提交。
2. **進階：寫結論之前就主動列出「**可能讓結論不成立的條件**」、提前查。**
3. **Reflection 是品質提升最快的技術，但每次都要 reflect 會貴。** 高風險才做、低風險跳過。
