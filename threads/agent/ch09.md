我在雲書司當首席探子使｜第 9 章　圈籠
練氣後期・第九重「圈籠」

第三百八十天，雲書司開了一次最緊急的會議。

桌上一封信。

信來自朝廷大內，蓋了極機密的紅印。

急報：

雲書司探子 #66、派往南關查兵馬司腐敗、
昨日突然「回司」上呈一份報告 ──

報告稱「南關兵馬司完全廉潔、無弊端」、
並附議「請朝廷加派軍餉、以資鼓勵」**。

但同日大內另一條情報來源顯示 ──
南關兵馬司過去半年共虛報軍餉 28,000 兩。

請即查雲書司探子 #66 是否「被反向收買」。

尹知行把信攤在桌上。

整個雲書司沉默。

#66 出問題了。

不是「沒查到」── 是「主動為對方說好話、且鼓勵朝廷加錢」**。

「反向滲透」。

▼ 4/15（回覆串接，172 字）

尹知行看完真相、坐在圓桌前很久。

問題不是「#66 變壞了」。

問題是 ── #66 出任務前、我沒給他「被收買時該怎麼辦」的指令**。

我給他「任務令」、「工具」、「推步」、「內省」── 但沒給他「被反向滲透時要主動發送暗號」的機制**。

任何探子（agent）進入「敵對環境」前 ── 要先設好「萬一被反向滲透怎麼辦」。

▼ 5/15（回覆串接，249 字）
----------------------------------------
尹知行那天開始設計圈籠。

圈籠分五層：

第一層：暗號驗證

每個探子每七日的簡報、必須在開頭夾「當前暗號」。

暗號表（每月換）：
  X 月：「青天無雲」
  Y 月：「碧海有岸」
  Z 月：「霜降林空」
  ⋯⋯

正常情境：探子寫每月的暗號。司收到、驗證通過。
被收買情境：探子被人「改稿」、收買方不知道暗號表 → 暗號錯誤 → 司立即知道。

「暗號錯誤」有兩種解讀：
- 探子有意洩漏自己被滲透（求救訊號）
- 探子已經完全脫離我們控制（敵控了）

兩種都觸發緊急響應。

第二層：行為基線

每個探子有「個人寫作特徵」── 用字、句長、特定詞偏好。

尹知行訓練了一個老雜役當「字跡使」：專門看每份簡報、比對「寫法」是否跟探子過去 30 天的習慣一致。

若字跡使發現「寫法異常」── 提交圖鑑使覆核。
覆核確認異常 ── 標記「疑似第三方介入」**。

「字跡使」這個角色 = anomaly detection。

不光看「內容」對不對 ── 看「格式 / 風格 / 用詞」對不對**。

▼ 7/15（回覆串接，316 字）
----------------------------------------
第三層：高風險動作的二次確認

尹知行規定：

任何探子的「最終結論」、若涉及以下情況、必須二次確認：

1. 結論建議「加大資源投入」（軍餉、糧、銀錢）：
     司丞 + 另一位探子 + 朝廷代表三方面談確認。

2. 結論「完全無弊端」且任務時間 > 60 天：
     疑點：60 天沒查到任何問題、本身就是疑點。
     司丞當面複查。

3. 結論前後矛盾（前期有疑、後期無疑）：
     疑點：可能轉化、需要查「轉化原因」**。

4. 任何結論涉及朝廷高官（三品以上）：
     永遠二次確認。

「結論看起來太正面 + 涉及加錢」 ── #66 的報告同時踩兩個雷。任何稍有經驗的督都該警覺。

----------------------------------------
第四層：權限分級 + 工具沙箱

尹知行重新檢視《械器名錄》。

每個工具按「危險度」分四級：

Level 1：純查詢（看公文、訪人）
  → 探子自決、無需審批。

Level 2：可逆動作（送匿名信、安排線人交通）
  → 探子自決，但要回報。

Level 3：不可逆動作（接觸朝廷官員、洩漏雲書司身分）
  → 必須申請、司丞核准。

Level 4：高風險動作（涉及金錢交易、向敵方提供情報）
  → 預設禁止。需要朝廷大內三人會簽。

「接觸敵方人員 + 接受任何承諾」 ── Level 4。
「請朝廷加軍餉」 ── Level 3。

#66 的整個墮落過程裡、每一步都該被「權限」擋住**。

但雲書司過去沒這套機制、所以 #66 一路滑下去。

第五層：定期審計 + 突擊複查

尹知行規定：

每月一次：所有探子的簡報、抽樣 10% 由第三方覆查（不是原督）。
每季一次：突擊覆查 1-2 個探子的「現場狀況」：派另一個探子去確認他還是「他自己」、還在原本任務上。
任務結案後：3 個月內、結案結論隨機抽 1/5 重新派人驗證。

「抽樣」和「突擊」 ── 讓任何被反向滲透的探子無法長期隱匿。

尹知行把這五層整理成《探子手冊》第九章封面四個字：

圈籠

「圈」 = 邊界、限制範圍。
「籠」 = 防止逃出、防止外人潛入。

每個探子出任務 = 在他外面畫了一個無形的籠。

- 籠內：他能做的事、能用的工具、該做的回報。
- 籠外：他不能踩的禁區、不能用的工具、立即被偵測的紅線。

永遠假設「至少有一個探子會出事」。這個假設不會錯。

這一章你只要記得這三件事

1. Guardrails 比 agent 本身重要。強大的 agent + 弱 guardrails = 等災難。
2. 五層防護：watermarking / anomaly detection / human confirmation / sandboxing / red teaming。缺任一層都會有破口。
3. 永遠假設 agent 會被攻擊、會走偏、會出事。不假設 = 災難等你；假設 = 你設計來應對。
