第三百零五天，尹知行在《探子手冊》第七章開頭寫：

內省 = 「自己反問自己」**

每一個結論寫完，先反問三個問題：

一、有沒有「反向解釋」？── 同樣的證據能否支持完全相反的結論？
二、有沒有「遺漏的變數」？── 我有沒有忽略某個重要因素？
三、有沒有「比對基準」？── 我說「偏高」、跟誰比？

通過三問還站得住的結論 ── 提交。
任何一問動搖的 ── 回去重跑。

南州「真金號」金舖虛報黃金含量、實際成色低於官標 5%。

[內省檢核]
反向解釋：成色 5% 的偏差可能是「煉金工藝差異」（每家金舖工藝不同）。
        → 我查過南州五家金舖、平均偏差 1-2%。真金號 5% 顯著高於市場。
        → 反向解釋不成立。

遺漏變數：真金號是否「新近改了工藝」、或「新進原料來源不穩」？

         → 無遺漏變數。

比對基準：「官標含量」用的是哪個版本？
         → 用「現行 2026 版」。真金號簽工標準用的也是現行版。
         → 基準正確。

結論：通過三問。提交。

這一章你只要記得這三件事

1. 每個 agent 結論寫完，反問三個：反向解釋 / 遺漏變數 / 比對基準。通過三問才提交。
2. 進階：寫結論之前就主動列出「可能讓結論不成立的條件」、提前查。
3. Reflection 是品質提升最快的技術，但每次都要 reflect 會貴。高風險才做、低風險跳過。
