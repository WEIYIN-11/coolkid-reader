練氣初期・第九重「連環問」

第七十二天，大長老正式來。

不是第五十一天那次「順便嚇人」的來。

是穿著正式長袍、由兩個侍者扶著、身後跟著閣主、後面再跟著阿土的那種來。

尹知行站在萬卷盤大廳中心，等。

大長老站在門口，看了一眼整個大廳，看了一眼木盤，看了一眼尹知行，最後看著閣主。

「就一個問題。」大長老說，「他答得出來，我給藏經閣三十兩黃金。答不出來⋯⋯」

老人停了一下。

「⋯⋯藏經閣關門。」

尹知行差點當場岔氣。

閣主沒說話。

尹知行回頭看閣主。閣主對他極輕地點了一下頭。

那意思是：你答。

「我師祖傳的『太初引氣訣』，」大長老開口，「能不能跟離火九轉訣的第七節合練？」

尹知行記下。

他在心裡先拆。

這個問題不是一個問題，是三個問題串著：

1. 「太初引氣訣」是哪本書？這本書的屬性是什麼？
2. 「離火九轉訣的第七節」是火屬性、築基末期。
3. 這兩者能不能合練？合練有什麼禁忌？

每一個小問題的答案，是下一個小問題的前提。

如果他一次把整句話拿去萬卷盤查，氣味會被「太初」「離火」「第七節」三個概念扯到不同方向，撈出來一堆雜亂的書。

他要做的，不是一次查找，是三次連續的查找。每一次的結果決定下一次查什麼。

尹知行報第一個氣味。

「太初引氣訣，引氣訣，書目。」

萬卷盤亮。亮的區域裡有 12 片，他抽前 5 片。

胡判事先已經坐在大廳一角的椅子上。他接過 5 片，看了一眼，圈出一片：

「《太初十二訣．引氣篇》。木屬性。三百年前留書。」

尹知行記下：「太初引氣訣」= 木屬性 + 三百年古書。

第一跳完成。

第二跳，他用第一跳的結果改氣味。

「離火九轉訣第七節，火屬性、築基末期，跟木屬性引氣訣的兼容性。」

萬卷盤亮。亮的區域比剛才小，更精準。10 片裡只有 3 片牽涉到「木火合練」。

抽出來給胡判。

胡判看了三片，每片時間都很長。最後他圈出一片：

「《五行合鳴錄．木火篇》。」

尹知行翻開那一片。

那一片寫的是：「木屬性引氣訣與火屬性築基功法合練，可。但須以木為先、火為後，逆之則氣亂。」

第二跳完成。

第三跳，他要確認「離火九轉訣第七節」具體是不是符合「火為後」這個條件。

他直接到萬卷盤報：「離火九轉訣第七節，氣脈走向。」

亮、抽、判。

胡判圈出 LH-007（這片他自己拆的）。

LH-007 寫：「離火九轉訣第七節，氣自湧泉上行至膻中，乃築基末期承接金丹之關鍵節。」

關鍵詞：「自湧泉上行」── 也就是說火氣是由下往上走。

而《五行合鳴錄》要的「先木後火」，是指先練木屬性引氣（內氣下沉至木脈），再練火屬性築基（火氣上行）。

兩個剛好對上。

第三跳完成。

尹知行把三片書按順序擺出來，遞給大長老。

「太初引氣訣是木屬性。」尹知行說，「《五行合鳴錄》記載，木火合練須先木後火。離火九轉訣第七節氣自下而上，符合『後火』的條件。」

尹知行停了一拍。

「可以合練。但有一個條件：每次合練前要先入木屬性引氣，待氣沉至木脈穩定，再起火屬性築基。順序錯了，氣會亂。」

大廳很安靜。

「你看過那本書？」

「⋯⋯今天看的。」尹知行說，「萬卷盤幫我找到的。」

尹知行回到桌前。

阿土在旁邊跳：「尹師兄！黃金！三十兩！」

尹知行沒理他。

他在意位圖旁邊空著的第十張紙條位置，寫了一句：

一個問題不夠，那就跑三個。

下面畫了一個流程圖：

問題進來
   │
   ▼
拆出第一跳該問什麼 → 跑流程 → 拿到中間結果
   │
   ▼
根據中間結果，問第二跳 → 跑流程 → 拿到中間結果
   │
   ▼
根據前兩跳結果，問最後一跳 → 跑流程 → 答案

每一跳都用他過去九章建好的全套（拆書、識意、萬卷盤、胡判、metadata、hybrid、HyDE、評估）。

唯一新的東西是 ── 「根據前一跳的結果，決定下一跳問什麼」。

這個決定，前世他靠 LLM 做。LLM 看了第一跳的結果之後，自己生出第二跳的查詢字串。

這個世界沒有 LLM。

但他自己就是 LLM。

第七十三天，尹知行開始教阿土「連環問」。

「你拿到一個問題，先問自己：這個問題有沒有可以拆成幾跳？」

「怎麼判斷有沒有可以拆？」

「看裡面有沒有『引用』。」尹知行說，「『我師祖傳的那本書』── 這就是引用。引用必須先查清楚『那本書是什麼』，才能答後面。」

阿土點頭。

「拆完之後，每一跳照原流程跑。跑完之後把結果記下來，作為下一跳的『已知條件』。」

「⋯⋯然後重複？」

「重複，直到所有跳都跑完。」尹知行說，「最後把每一跳的答案串起來。」

阿土在筆記本上畫小人。

他把這個會走來走去、會自己決定下一步的小人叫問道童子。

尹知行覺得這個名字比探子（agent）順耳。

那晚，尹知行最後一次走過萬卷盤大廳。

木盤上現在已經有八十萬片書。每一片都有氣味標記、有 metadata 標籤、有編號、有跟相鄰書的連結。

九十二天前，他帶著一個喪鐘和一杯涼咖啡死在會議室。

今天，他在一座修真宗門的藏經閣裡，建好了一整套會自己回答問題的系統。

沒時間、先 ship、有問題之後迭代。

他想起前世聽過最多的那句話。

這一次，他先把根做對了，再 ship。

明天的大典禮，不會像第 1 章那個 demo 一樣翻車。

不是因為他這次沒幻覺。

是因為他這次知道幻覺從哪裡來，而且他的系統會說「我不確定」。

這一章你只要記得這三件事

1. 多跳問題救不了單次 retrieval。要拆成幾跳、每一跳的結果決定下一跳。
2. Agentic RAG = LLM 自己決定下一步該查什麼。核心是 ReAct 迴圈：想 → 做 → 看結果 → 再想。
3. 跑 agent 要有護欄。最大跳數、stop condition、每一步的 log，都要有。LLM 想偏的時候要救得回來。
